# Security policy

This policy applies to every repository in the `inteliwertai` organization that does not
have its own `SECURITY.md`.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting. Do not
open a public issue, pull request or discussion.

1. Open the repository the problem is in.
2. Go to the **Security** tab and choose **Report a vulnerability**.
3. Describe the problem, the affected version or commit, and the steps to reproduce.
   Leave out real credentials and data you are not allowed to share.

If the problem is in Inteliwert software that has no public repository, report it on
[inteliwertai/.github](https://github.com/inteliwertai/.github/security) the same way.

We acknowledge reports in the advisory thread, keep you updated there while we work on
a fix, and credit you in the published advisory unless you ask us not to.

## Supported versions

Unless a repository's own `SECURITY.md` says otherwise, only the latest commit on its
`main` branch is supported.
